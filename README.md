The pupose of this lab is to practise writing core Python code using variables, expressions, conditionals, and loops. The lab also teaches step by step in a Jupyter Notebook how to apply logical thinking, document code clearly, and version work using Git and GitHub.

Below is a summary of learning objectives:

. Declare and manipulate variables using core Python syntax
. Apply conditionals to control program logic
. Use loops to automate repetitive tasks
. Write clear, readable, and well-documented Python code
. Trace code execution to predict outputs and identify basic logic errors.
. Version work using Git and GitHub
